## 📌 Project Overview


*Functional Treat* is a complete menu-driven *Data Analyzer and Transformer* program written in pure Python.  


This project demonstrates strong command over Python functions by performing analysis and transformations on *1D and 2D list-based data*.


It covers all major functional programming concepts required in the assignment

- Built-in functions
- User-defined functions (UDF)
- *args, **kwargs and __doc__
- Recursion
- Lambda functions
- Global keyword
- Returning multiple values
- Sorting & transforming collections
- Handling 1D & 2D lists

---

## 🚀 Features

| Feature                      | Description                                      |
|-----------------------------|--------------------------------------------------|
| Data Input                  | Accept 1D or 2D list (manual or sample data)    |
| Built-in Functions          | len(), sum(), min(), max() etc.         |
| User-defined Functions      | Average, Duplicates, Unique values              |
| *args, **kwargs & _doc_   | Flexible arguments + documentation              |
| Recursion                   | Factorial & Fibonacci sequence                  |
| Lambda Functions            | Filter data using threshold + map/filter        |
| Global Keyword              | Shared dataset summary across functions         |
| Multiple Return Values      | Min, Max, Sum, Average in one function          |
| 1D & 2D Array Support       | Nested list handling + formatted grid display   |
| Sorting                     | .sort() (in-place) vs sorted() (new list)   |
